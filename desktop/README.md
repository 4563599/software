# Desktop 悬浮栏工具

Windows 桌面常驻悬浮栏，包含 C、AS、T 和工具（扳手图标）四个按钮。所有客户端、后台、服务端和测试源码均在本目录，不依赖原电脑的固定盘符。

## 四个按钮

| 按钮 | 功能 |
| --- | --- |
| C | 经确认和管理员授权后，关闭 Codex、ChatGPT、Claude 及确认归属它们的后台进程；多轮重新扫描，报告残留；保留悬浮栏、T 工具和无关系统进程。 |
| AS | 经确认后关闭 Android Studio、Gradle、ADB、模拟器及相关子进程。未保存的 IDE 内容可能丢失。 |
| T | 备忘录、AI 提示词、账号密码、配置（代码高亮）、待办资料库。默认快速复制列表，支持搜索、分类、置顶、查看/编辑、三栏管理、加密备份及多电脑同步。记录里的网址可以点击，用默认浏览器打开。 |
| 工具 | 安卓开发小工具窗口：查看当前 Activity、查看任务栈、安装 APK、手机截图、截长图、导出蓝牙日志、显示日志（含导出 AP 日志）、蓝牙日志解析、停止 Gradle、注销安装商账号、AI 对话记录。连了多台手机时在顶部选择要用的那台。 |

### 点击和等待

- 整个悬浮栏都能点：按钮之间的空隙各归两边的按钮，四周边缘归最近的按钮。点击时手稍微移动一点（按 Windows 的拖动距离，至少 6 像素）仍算点击，移得更远才是拖动悬浮栏。
- 点一次就有反应。悬浮栏还在处理上一次点击时多点的几下会被丢掉，不会刚打开窗口又被收起。
- 需要等待时，按钮上方会出现一个白色小卡片，左边是转动的蓝色圆圈，写着“正在打开 T 笔记…”“正在打开开发工具…”或“正在关闭 …”。窗口出来或关闭完成后卡片自动消失；30 秒内窗口没有出来，卡片变成红色的“没有打开，请再点一次”，3 秒后消失。卡片不抢焦点，也不挡鼠标点击。
- T 笔记窗口已经开着时，点 T 直接把它拿到前面（不再先查一遍后台进程），后台服务的检查放在窗口出来之后。窗口没开时，在悬浮栏自己的进程里启动，不再另开一个 PowerShell，大约快一秒。
- 开发工具窗口没开时，启动需要一到几秒（电脑刚开机时更久），期间再点不会再启动一份。

### 关闭和退出

- T 笔记和开发工具窗口右上角的关闭按钮（X）改成最小化：窗口和里面的内容都保留，下次点 T 或工具按钮马上出来，不用重新加载。开发工具从最小化恢复时会重新读取一次手机列表。
- 真正退出：按住 Shift 再点 X；或者按 Alt+F4；或者在悬浮栏上点右键，选“退出 T 笔记”或“退出开发工具”（窗口没开时这一项是灰的）。T 笔记还可以在任务栏图标上右键“关闭窗口”。T 笔记里有没保存的修改时，退出前照样会先提醒。关机、注销时两个窗口都会正常关闭。
- T 笔记是 Edge 的应用窗口，网页本身拦不住它的关闭按钮，所以由悬浮栏在后台单独一个线程里只看鼠标左键点在 T 笔记关闭按钮上的那一下，把它换成最小化（`t-notes\CloseGuard.cs.txt`），别的点击都不受影响。悬浮栏没在运行时，关闭按钮照常关闭窗口。

### 工具按钮

- 和 T 一样只开一个窗口，显示在按钮正上方；窗口在最前时再点一次收起。
- **查看当前 Activity**：Activity 名称用粗体蓝字突出显示，下面是完整类名和包名；读不到 Activity 时改看焦点窗口，并附上 `dumpsys` 的原始行。
- **查看任务栈**：在单独的窗口里把手机上的每个任务栈画成一张卡片（最近使用的在前）。卡片标题是任务 ID、Activity 数量、应用包名，以及“前台 / 桌面 / 最近任务”标记；下面是一个开口朝上的“栈”，Activity 一块一块叠在里面，上面标“栈顶”、下面标“栈底”，正在显示的那块是蓝色。类名太长会截断，鼠标悬停在卡片上可看完整类名；“刷新”或 F5 重新读取。没有 Activity 的空容器（分屏、自由窗口）不画。
- **手机截图**：截取所选手机的屏幕，保存为桌面上的 `phone_screenshot_年月日_时分秒.png`，同时复制到剪贴板，并打开预览窗口。预览窗口里的“复制图片”随时可以再复制一次（例如中间复制过别的东西），也能打开图片或所在文件夹。手机上正显示受保护的画面时系统禁止截屏，例如小米的“安全键盘”在输入密码时弹出，这时工具会说明原因（收起键盘后再截，或在手机设置里关闭安全键盘），而不是笼统地报“截图失败”。
- **截长图**：先在手机上打开要截的页面并停在开头，再点按钮。工具会自动向下滑动、每屏截一张，按重叠的内容对齐后拼成一张长图（保存为 `phone_long_screenshot_*.png`，复制到剪贴板并预览）。滑到底部、达到 12 屏或点“停止截图”时结束；每屏大约 3.5 秒（要等滚动条消失，否则它会出现在长图里）。顶部标题栏只保留第一屏的，底部导航栏只保留一次；Samsung 列表在屏幕边缘画的圆角不会混进拼接处。页面里随滚动变化的内容（动画、视频、浮动按钮）可能在拼接处不完全一致。
- **安装 APK**：打开安装窗口，把 APK 拖进去（也可以直接拖到开发工具窗口上），或点击选择文件。窗口显示 App 名称、包名、版本，以及手机上已装的版本（用 SDK build-tools 里的 aapt 读取）。安装选项 `-r`（覆盖安装，保留数据）、“清除数据”（先 `adb uninstall` 卸载手机上的旧版本、删除 App 的全部数据，再全新安装；勾选后 `-r` 变灰不再适用，也顺带解决签名不一致和降级问题）、`-t`（允许测试包）、`-d`（允许降级）可以勾选，会记住上次的选择，下面显示实际执行的命令。“清除数据”每次真正卸载前都会弹窗确认，写明 App 名称和手机上的版本；点“否”什么都不改。手机上没装这个 App 时直接安装；卸载失败时不会继续安装，并说明原因。选项和 APK 不匹配时先用红字提醒，例如“这是测试包，需要勾选 -t”“手机上的版本号更高，需要勾选 -d”。结果同时显示在安装窗口和主窗口：成功时说明是新装还是覆盖了哪个版本；失败时用中文说明原因和建议，并附上错误码和 adb 的英文原文（例如签名不一致、版本降级、测试包、存储不足、小米未开“USB 安装”）。安装到开发工具窗口顶部选中的手机。
- **停止 Gradle**：结束所有 Gradle 守护进程、Wrapper、工作进程和 Kotlin 编译守护进程，列出每个进程是否已结束。Android Studio 本身和其他 Java 程序不受影响。不需要先确认，正在进行的编译会中断。
- **导出蓝牙日志**：把手机上的日志目录复制到电脑。每台手机一个子文件夹，例如 `E:\BLELogs\Mi_10_a1b2c3d4\BLEBluetoothLog`，两台手机的日志不会混在一起；完成后打开该文件夹。
- **显示日志**：打开一个占大半屏幕的窗口，像资源管理器一样浏览手机文件。顶部地址栏可以直接输入手机路径（例如 `/sdcard/Download`）后按 Enter，旁边是后退、前进、上一级和刷新按钮（快捷键 Alt+←、Alt+→、Backspace、F5）。双击文件夹打开，单击文件在右侧查看内容；刷新会重新读取当前文件，方便看不断增长的日志。打开时自动进入日志目录里最新的文件夹并显示最新的日志、滚到末尾；可以按文字筛选行。`[CONNECT]`、`[DISCONNECT]` 等标签补齐到同样宽度，后面的框线左边对齐。非文本文件和超过 64 MB 的文件不在这里显示。地址栏右边的“保存到电脑”（也可以右键或 Ctrl+S）把左边选中的文件或整个文件夹从手机复制到电脑：文件会弹出“另存为”可以改名，文件夹选一个目标位置；保存的是手机上的原文件，不受筛选影响，完成后在资源管理器里选中它。下次保存默认打开上次保存的文件夹。
- **导出 AP 日志**（日志窗口里“保存到电脑”旁边）：把 Octopus 里“AP 日志下载”下载的日志复制到电脑。这些文件在 App 的私有目录 `cache/charger_logs/<桩 SN>/` 里，文件管理器和 `adb pull` 都读不到，只能通过 `run-as` 读取，所以**只有 debug 包可以导出**；正式版（release）会直接提示无法读取。导出到“导出到电脑”位置下的 `<手机>\charger_logs\<桩 SN>\`，还没下载完的 `.download` 文件跳过，每个文件核对大小，完成后打开文件夹。App 的包名在主窗口“AP 日志 App”里填，默认 `energy.octopus.installer`，别的构建版本改成对应包名即可。
- **蓝牙日志解析**：把 SDK 的蓝牙收发日志还原成一条条“请求 → 应答”，说明每条是什么功能、用的什么指令、每个字节怎么解析。日志来源有四种：打开窗口后自动实时采集所选手机的 logcat（只读开始之后的新日志，可暂停）；“粘贴日志”；“打开日志文件”或把 `.log` 文件拖进窗口；以及在“显示日志”窗口里点“蓝牙解析”，把右边正在看的手机日志直接交过来。手机上的日志文件格式（`[时间] [SEND] │…`）、logcat、Android Studio 复制的日志、每行一条 `FB 06` 开头的原始 HEX 都能识别。左边列表每条显示功能名、状态、耗时、`0xA8 → 0x08` 这样的指令码和收发时间，上方可以只看某一类指令、只看异常或隐藏每隔几秒一次的实时数据轮询。中间是所选报文：发送 / 接收切换、16 字节一行的原始 HEX（左边行号加上面列号就是字节位置，选中字段的字节标蓝）、字段表（文档序号、位置、字段、HEX、解析结果、协议页码；「文档序号」是这个字段在协议章节表格里的序号，从协议 HTML 的表格按长度累加自动对上，打开章节就能按序号找到），“解析过程”按“帧结构与校验 → 逐字段（字节 → 数值）→ 结论”写出来，“调用与参数”给出 Octopus 里的调用位置和 SDK 方法。右边「协议章节」列出这条报文相关的章节（自己的指令、对应的请求或应答、字段引用的附录、1.2 报文格式定义），点一下打开协议章节窗口：左边是协议的全部标题，右边只显示所选标题下的内容，跨页的部分无缝接在一起（跨页的表格看起来是一张连续的表，页码只在窗口顶部显示），不混入其他标题；文字可以选中复制，Ctrl+F 查找，Ctrl+滚轮缩放，「在浏览器中打开」用默认浏览器看同一节。章节来自把协议 PDF 转成的 HTML：自动找 `协议文档\蓝牙协议\*蓝牙模式协议*.html`，也可以点「选择协议文件…」指定（原 Word 文件被加密软件加密，读不出内容）；没有 HTML 时仍按页码打开 `协议文档\蓝牙协议新png` 里的原图。字段表下的「查看协议章节」打开当前字段所在的章节，并用红框圈出它在协议表格里的那一行、滚动到那里（一行跨页时两页的部分都圈出）；章节窗口开着时，在解析窗口里换选字段，红框会跟着移到新的那一行。目前逐字段解析覆盖 Octopus 用到的指令：实时充电数据 A8/08、桩信息设置/查询 AA/0A（SN、时间、最大电流、桩模式、ATE、负载平衡、电网类型、过压阈值、指示灯亮度、状态、基础信息）、故障列表 B6/16、RCD 测试 B7/17；其他指令显示为原始数据。SDK 不记录内容的敏感指令（如 0x0E）只显示指令码。
- **AI 对话记录**：查看和搜索在 Claude（Claude Code / Claude 应用的 Code 页）和 Codex（Codex 应用 / CLI）里的每一轮对话：你问了什么、AI 回答了什么、什么时候。不用手动保存：Claude 会把每次对话记在 `%USERPROFILE%\.claude\projects\<项目>\<会话>.jsonl`，工具直接读这些记录，以后的对话也会自动出现（窗口重新激活时自动刷新，也可以点「刷新」）。Claude 会自动清理一段时间以前的记录，所以工具把提取出来的问答另存一份到 `E:\AIRecords\sessions`（每个会话一个 gzip 压缩文件，约为原大小的 37%；没有 E 盘的电脑存到 `%LOCALAPPDATA%\TNotes\ai-records`，设置环境变量 `TNOTES_AI_RECORDS` 可以换位置），原记录被清理后也还能搜到。随手记后台每半小时检查一次，有新对话就自动另存，不打开窗口也不会漏。以前存在 `%LOCALAPPDATA%\TNotes\ai-records` 的旧记录第一次打开时自动搬过去。**同步**：随手记后台把这些压缩文件加密后同步到随手记的服务器，其他电脑上的对话也会出现在这里（标「来自 电脑名」）。加密用随手记资料库的密钥，服务器只看到密文，也看不出是哪个会话；AI 记录放在服务器上单独的存储里（上限 32 MB），随手记本身每 30 秒的同步不会下载它们，只有变了的会话才传。需要两个条件：随手记登录时勾选了「记住这台电脑」，并且服务器已升级（见 [t-notes/README.md](t-notes/README.md) 的「升级服务器」）；没满足时窗口顶部会写明原因，记录照样存在本机。窗口顶部显示保存位置和上次同步的时间、服务器上占用的空间。左边先按来源分成 Claude 和 Codex 两组（各有颜色标记，点组名看这一组的全部），组里再按项目分（对话所在的 git 仓库文件夹名，例如 software、Octopus；不在项目里的是「临时会话」）。Codex 把对话存在 `%USERPROFILE%\.codex` 的 SQLite 数据库里，工具用 Node 自带的 SQLite 只读地导出（`t-notes\client\codex-records.cjs`，需要 Node 22.13 以上），每个 Codex 会话存成 `codex-<会话>.json.gz`，和 Claude 的记录一起保存、搜索、同步；只收你自己发起的会话，不收子任务和审批检查，自动化任务发起的一轮会标出来。Codex 组里的项目名和 Codex 侧边栏一致（读 `.codex-global-state.json` 里的项目归属，没有归属的才用文件夹名）；Codex 输入框发来的问题是 Markdown，粗体、代码按 Codex 的样子显示，附件说明只留文件名，中间是这个项目的对话，最新的在上，每条显示你的问题、回答的第一句（搜索时是关键词附近的一句）、时间和会话标题；右边是这一轮的完整内容：你的问题、过程说明（边做边写的几段话）、最后的回答，回答里的标题、表格、列表、代码都按统一的样式排版。顶部搜索框输入关键词（空格分隔多个词，全部包含才显示），右边会把所有匹配标黄并滚到第一处。只读取对话文字，不读取工具调用的细节、图片和子任务。
- **注销安装商账号**：把桌面上原来的 `注销安装商账号.cmd` 搬进来，打开一个单独的窗口。顶部选环境 `dev` / `pre`（旁边显示服务器地址，会记住上次的选择）。拿 Token 有两种方式：① 填邮箱和密码点“登录”（或按 Enter），邮箱和密码先用服务器证书公钥加密（和 App 里 `EccEncryptUtil` 一样的 ECDH P-256 + HKDF-SHA256 + AES-256-GCM），再调用 `app/installer/user/login`，成功后 Token 自动填入；② 直接粘贴 Token，或点“从手机读取”，从所选手机的 logcat 里找 App 最近一次登录或注册返回的 Token、userId 和邮箱。Token 下面一行说明它属于哪个账号（手动粘贴的显示“不知道是哪个账号”）。红色“注销账号”调用 `app/installer/user/delete`（请求头带 `satoken`），每次都先弹窗确认，写明环境和账号，默认按钮是“否”；注销后账号不能恢复。结果同时显示在这个窗口和主窗口，只显示 Token 的头尾几位；失败时附上服务器的错误码和原始回复。注销成功后记得清除手机上 App 的数据再重新注册（App 还缓存着旧 Token）。登录成功后会记住邮箱和密码，下次打开自动填好：都只保存在本机的 `%LOCALAPPDATA%\TNotes\dev-tools.json`，密码用 Windows DPAPI 加密（只有当前 Windows 用户在这台电脑上能解开），不写进仓库。
- 主窗口“日志路径”里的蓝牙日志目录、AP 日志 App 和电脑上的导出位置都可以修改，自动保存到 `%LOCALAPPDATA%\TNotes\dev-tools.json`；“默认”恢复为 `/sdcard/Android/data/com.enplus.caro_sdk/files/BLEBluetoothLog` 和 `energy.octopus.installer`。
- 需要 adb：先找 PATH，再找 `ANDROID_HOME`、`ANDROID_SDK_ROOT` 和 `%LOCALAPPDATA%\Android\Sdk`。

- 悬浮栏可拖动，保持置顶，并记住拖动后的位置（原来的屏幕拔掉后回到主屏右下角）；每分钟检查并恢复悬浮栏和本地笔记后台。
- 右键“退出悬浮按钮”是真正退出：守护任务不会再把它拉回来，下次登录或双击桌面 `Desktop Tools` 才恢复。悬浮栏意外崩溃仍会在一分钟内自动恢复。
- T 是开关：一次只开一个笔记窗口，窗口已在最前时再点一次收起，否则把它唤到最前。每次点 T，笔记窗口都显示在 T 按钮正上方（靠近屏幕边缘时贴边，上方放不下时显示在下方）；点窗口里的布局按钮切换到资料库大窗口时，窗口保持底边和中心位置放大，再点一次缩回原处，始终停在按钮上方。
- T 记住登录后（登录页“记住这台电脑”默认勾选）打开就直接进入，不用再输主密码；刚开机或本地后台刚重启时会自动重试约 20 秒（显示“正在自动登录…”），而不是退回登录页。只有点了“退出登录”才需要重新输入主密码。每次打开都回到上次的位置：速记还是资料库、所选分类、上次打开的记录，以及列表滚动到的位置（只在 T 窗口自己的浏览器存储里记记录编号和分类名，不存任何内容）。
- 查看记录时，“编辑 / 置顶 / 复制 / 删除”是固定在面板底部的一排大按钮，带文字，内容滚动时也不动；在回收站里“删除”变成“恢复”。记录正文、标题和账号栏的字比以前大一号。
- 笔记里的网址会自动变成蓝色链接：查看记录时，内容和标题里以 `http://`、`https://` 或 `www.` 开头的地址、以及账号密码的“网站”栏（写成 `github.com` 也行）都可以点击；速记列表里带网址的记录多一个“打开链接”按钮。链接由本地后台交给 Windows，用你的默认浏览器打开并切到前面，而不是在 T 窗口里打开。只接受 http / https 网页地址，不会打开本机文件或程序。
- 悬浮栏按钮统一使用蓝色系，不使用绿色。
- 悬浮栏的画面如果没画出来或意外丢失（例如登录时桌面还没准备好），会在几秒内自动重画；重画失败的记录写在 `%LOCALAPPDATA%\TNotes\toolbar-diagnostic.log`，只记时间和原因，不含笔记内容。
- 通过无窗口启动器运行，避免定时弹出黑色命令窗口。
- 笔记后台独立运行，不依赖 Codex 或 Claude 的存活。
- 点击 C 不会修改代理、系统安全设置或删除笔记文件，也不会把所有同名 Java / Runtime Broker 一概结束。

## 在另一台 Windows 电脑安装

要求 Windows 10/11、Windows PowerShell 5.1、Node.js 22 以上，以及 Edge 或 Chrome。安装 Node.js 后，打开新的 PowerShell 终端。

```powershell
git clone https://github.com/4563599/software.git
cd software\desktop
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Install.ps1 -DryRun
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Install.ps1
```

安装后创建桌面 `Desktop Tools` 快捷方式及当前用户启动项，代码仍在克隆下来的 `desktop` 文件夹。不要随意移动该目录；移动后重新安装即可更新路径。

已有旧版运行时，先保存草稿，按下一节把原服务器地址和公开证书配置到私人数据目录，再明确使用 `Install.ps1 -ReplaceExisting` 迁移本工具的任务和启动项。安装不会删除用户数据，也不会修改无关任务。`-NoStart` 只配置、不立即启动。也可以直接双击 `Start-Desktop.vbs` 临时启动悬浮栏。

安装管理的本地任务：

- `TNotesFloatingToolbarWatchdog`：登录后和每分钟检查；静默运行。
- `TNotesLocalBackend`：独立运行笔记后台，无运行时长上限。

## 配置已有同步服务器

仓库不包含真实服务器地址、证书、初始化令牌或密码。每台电脑分别取得服务器的公开证书，并执行：

```powershell
.\Configure-Notes.ps1 -ServerUrl https://notes.example.com:18443/ -ServerCertificate E:\private\server-ca.pem
```

配置写到当前用户的 `%LOCALAPPDATA%\TNotes`，不会写到仓库。配置后关闭并重新打开 T；如果旧后台仍在运行，可先保存草稿，再重启 `TNotesLocalBackend` 任务。

- 第一次部署的所有者可使用 `-Enrollment`，在隐藏提示中输入一次性初始化令牌。不要把令牌放进命令行、聊天或 Git。
- 其他电脑不需要初始化令牌，直接登录同一资料库名称和主密码。
- 不要复制其他电脑的 `remembered-session.dpapi`；每台电脑独立记住登录。
- 只更换服务器连接配置，不自动把现有资料迁移到另一个服务器。换服务器前请保留加密备份。
- 无服务器配置时可以本机加密使用；不要把本机离线资料库和另一台电脑的不同资料库当成同一库覆盖。

## 首次部署 Linux 服务器

需要 Python 3.10+、OpenSSL、systemd 和具有安装权限的 SSH 用户。仅适用于新的 `/opt/tnotes`、`/var/lib/tnotes`，不会覆盖已有安装或改动现有网站。

```powershell
python -m pip install -r requirements-dev.txt
python tools\deploy_server.py --host notes.example.com --fingerprint SHA256:填写你核对过的SSH指纹
```

部署时会隐藏输入 SSH 密码，并强制比对事先核对的主机指纹。连接文件和一次性初始化令牌默认保存到当前用户的私人数据目录，不回显令牌。若该目录已有服务器配置，部署工具拒绝覆盖，可用 `--output-dir` 指向仓库外的另一个私人目录。

默认 HTTPS 端口为 `18443/TCP`；按需配置云安全组。SQLite 仅在服务器本机使用，不对外开放数据库端口。服务使用独立的低权限 `tnotes` 用户，定时做一致性备份，保留最近七份。

## 数据与安全

| 内容 | 位置 / 处理 |
| --- | --- |
| 本机加密缓存、登录记忆、私人连接配置 | `%LOCALAPPDATA%\TNotes`，不属于源码 |
| 每日自动备份（密文） | `文档\TNotes-Backups`，可在笔记的“同步与备份”里改到其他文件夹；保留最近 30 份 |
| 悬浮栏位置 | `%LOCALAPPDATA%\TNotes\toolbar.json` |
| 工具窗口的日志路径、上次选的手机和上次保存的文件夹 | `%LOCALAPPDATA%\TNotes\dev-tools.json` |
| 服务端加密数据库 | `/var/lib/tnotes/vault.sqlite3` |
| 每日服务端备份 | `/var/lib/tnotes/backups` |
| 源码、图标、模板和测试 | 本目录，可提交 Git |
| Node.js 二进制、浏览器缓存、安装包、真实笔记和凭据 | 不提交 Git |

笔记标题、正文、账户、密码、标签采用客户端 AES-256-GCM 加密。主密码不落盘；记住登录仅保存 Windows DPAPI 当前用户加密保护的派生密钥。HTTPS 校验专用证书及主机名，不跳过验证；短暂断连采用有限的安全重试。

记住登录后，同一 Windows 用户可以直接查看资料，离开电脑请锁屏；退出登录会清除本机登录记忆。主密码无法找回。此自用工具尚未经过独立安全审计，重要密码请保留可靠备份。

`.gitignore` 是防误提交的辅助措施，不是脱敏器。提交前仍需检查暂存区，不能直接复制整个用户数据目录或本机程序目录。
