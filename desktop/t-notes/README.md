# T Notes

Windows 轻巧速记小窗 + 三栏资料库。点击窗口右上角的布局按钮切换。

速记小窗平时在 T 按钮正上方。在小窗里点开任何一条记录（备忘录、提示词、账号密码、配置、待办），窗口从工具栏那边展开：右边和下边留在小窗原来的位置，向左、向上变大（不会超出屏幕）。宽度按记录里最长的一行来定，尽量让每一行文字都在一行里显示完（最宽到屏幕放得下为止，最窄 560 像素），高度按内容来定，短的记录窗口就小，长的最多到屏幕高度。点返回回到列表时，窗口回到原来 T 按钮上方的位置和大小（中途刷新页面也一样）。切换到资料库时，窗口同样从工具栏那边向左、向上放大（约 1480×940，屏幕小时相应缩小）；切回速记时回到原来的位置。窗口变大期间如果又点了 T（窗口会挪到按钮上方），切回时小窗跟着按钮走，不会跑远。

出错的提示不再浮在页面上挡住内容，而是记到错误日志里：底部状态栏右边出现红色的“N 个错误”，点开能看到每条错误和出错时间（最新的在上面）。之后保存成功时，之前的保存错误会被划掉，并注明“已于 今天 16:50 保存成功”；同步出错则在之后同步成功时划掉。错误都处理完后按钮变成灰色的“错误日志”，可以在里面“清空日志”。日志只记提示文字，不记录内容，保存在这个窗口的浏览器存储里，最多保留最近 100 条。在“同步与备份”等对话框里出错时，提示显示在对话框最下面，不盖住对话框里的内容。列表里每条的标题、说明和预览都只占一行，放不下的部分显示“…”，鼠标停在上面可以看到完整标题，点开就能看到全部内容。记录的时间显示为“今天 16:24”“昨天 09:10”这样的简短写法。

## 使用

1. 解压便携包后运行 `Start-TNotes.cmd`。需要 Edge / Chrome；便携包附带 Node.js 运行时，源码版需要 Node.js 22 以上。
2. 仅首次部署的电脑可以创建资料库。设置一个至少 12 字符的主密码，不能找回。登录时默认勾选“记住这台电脑”；只在自己信任的 Windows 用户下使用。
3. 其他电脑运行相同便携包，首次输入相同资料库名称和主密码登录。不要再次创建资料库。每台电脑分别记住登录，登录密钥不随安装包分发。
4. 打开默认进入快速复制列表，搜索框直接获得焦点。备忘录和提示词可一键复制正文；账号记录分别提供“复制账号”和“复制密码”。支持分类筛选，置顶记录排在前面。点击标题查看详情，点击铅笔进入编辑；小窗保存后返回列表。点击保存立即加密落盘；联网时自动同步，每 30 秒检查一次。冲突记录另存副本，不覆盖任一方。
5. 离线使用需要先在该电脑完成至少一次登录和同步。主密码不会写入服务器配置或客户端安装包。不启用记住登录时，重开窗口需要主密码。
6. 记住登录后，重开窗口、重启程序或重启电脑均无需重复输入主密码；不再闲置自动锁定。右上角“退出登录”会清除当前电脑的登录记忆，并让本程序的其他未编辑窗口一起退出；有未保存修改的窗口会保留内容并提醒先保存后退出。下次打开必须重新输入主密码。
7. 本地服务重启后，新版页面会自动恢复页面校验再重试一次，不要求重置主密码。从旧版升级时，仍打开的旧窗口需刷新一次；出现 `Invalid local request` 不代表主密码错误。
8. 分类与新建类型联动：备忘录对应备忘录，AI 提示词对应提示词，保险箱对应账号密码。新建草稿切换分类会保留输入内容；修改类型下拉框也会选中对应分类。查看其他分类不会自动修改已有记录的类型。
9. 本机安装了独立的 `TNotesLocalBackend` 后台任务，由每分钟守护检查本地健康状态。后台恢复不会刷新窗口或清空未保存内容；点击 T 也会先检查后台，再唤起窗口。便携版可使用 `Launch.ps1 -BackendOnly` 只启动后台。
10. 快捷键：Ctrl+N 新建，Ctrl+S 保存，Ctrl+F 搜索，Esc 取消编辑、返回列表或清空搜索。搜索范围是标题、正文、账户、标签和网站，不包含密码。带 `{{变量}}` 的提示词在列表里点一下会先让你填变量，再复制填好的结果。回收站里的记录，右上角按钮是“恢复”。
11. 每日自动备份：后台每天把加密后的资料库保存为 `文档\TNotes-Backups\tnotes-backup-日期.json`，当天有改动会更新当天的文件，保留最近 30 份。在“同步与备份”里可以改备份文件夹（建议放到另一块硬盘）或立即备份一次。备份文件全部是密文。
12. 导入与恢复：登录后在“同步与备份”里“导入加密备份”，不会覆盖现有记录——本机没有的记录直接恢复，内容不同的另存为“备份副本”，同一个文件重复导入不会重复添加。电脑上还没有资料库时，登录页有“从加密备份恢复”，选择备份文件并输入它的主密码即可；主密码校验通过之前不会写入任何数据。
13. 云端短暂断连会进行最多三次安全重试；记录写入重用同一份密文，避免重复录入。证书校验失败不会跳过校验或反复重试。网络错误日志只记录错误码与次数，不记录账户、密码或正文。
14. 待办：点“待办”分类，上面的输入框有两行：第一行“添加待办”是标题，打字、回车就加一条，输入框留着可以接着加，Esc 清空；第二行“内容”写备注，可以不填。Shift+回车或 Ctrl+回车在内容里换行（在标题里按是跳到内容），粘贴多行文字会保留换行，内容框会跟着变高；多行文字粘贴到标题里会自动放进内容。填了标题时，内容整段作备注；没填标题时，内容的第一行作标题，其余作备注。加完一条光标回到标题，接着加下一条。标题右边可以填标签，点进去或点小箭头会列出用过的标签（最近用的在前，打字可以缩小范围），点一个就填上；待办全部删除了的标签不再列出。下面的标签按钮（带未完成数量）用来筛选，没有未完成待办的标签不显示按钮（正在筛选的那个除外），筛选某个标签时新加的待办自动带上这个标签。列表每条显示标签和添加时间，已完成的显示完成时间，按添加时间从新到旧排，编辑不会改变顺序。点前面的圆圈完成，完成的收进下面的“已完成 N”（点一下展开，再点圆圈可以改回未完成）；“清除”把已完成的全部移到回收站；选中某个标签后，标签按钮最右边有红色的“删除全部”，确认后把这个标签的待办（包括已完成的）一起移到回收站，在回收站里可以逐条恢复。待办是单独的功能，不出现在“全部”“已置顶”和它们的搜索里，只在“待办”（和回收站）里看得到。点标题打开详情，可以加备注、标签、置顶，底部“完成”按钮代替了“复制”。待办和其他记录一样加密保存、同步和备份，编辑内容不会改变完成状态。添加、完成、置顶和删除会立刻显示，加密保存在后台按顺序进行，停手约 1.5 秒后再统一同步一次，不会因为正在和服务器同步而卡住；保存失败会撤回这次修改并提示，还没保存完就关窗口会先提醒。
15. 配置：点“配置”分类，新建一条，把配置或代码粘贴进“配置内容”（等宽字体、不自动换行），“说明”里写这段配置做什么用、要注意什么。查看时代码带行号、按语法着色，注释用绿色斜体单独标出，长行在行号右边折行，复制时不会带上行号；说明显示在代码下面，里面的网址可以点击。格式默认“自动识别”，输入时就会显示认出的格式，认错了可以手动选：JSON（含注释）、YAML、INI / TOML / .env、XML / HTML、Shell、PowerShell、CMD / BAT、JavaScript / TypeScript、Java / Kotlin / C# / Go、Python、SQL、CSS、Nginx / SSH 等配置，或纯文本。代码框右上角和每条右边的“复制”只复制配置内容。配置和待办一样是单独的功能，不出现在“全部”“已置顶”和它们的搜索里；在“配置”里搜索会搜到代码和说明。着色在本机完成，内容只当文字显示，不会被当成网页代码执行。
16. 右键菜单：在速记列表和资料库列表里，任何一条记录点右键都会弹出菜单，里面是这条记录能做的事：查看、编辑、置顶（或取消置顶）、复制（账号密码是复制账号和复制密码，带变量的提示词是填充变量后复制，配置是复制配置，待办是复制文字），有网址时可以用默认浏览器打开，待办还有标记完成；最下面是红色的“删除”，点一下就移到回收站，不再二次确认，正在编辑且没保存的那条会先提醒。回收站里右键是“查看”和“恢复”。待办的标签按钮点右键是“删除这个标签的全部待办”，会先确认数量。按住 Shift 再点右键，出现的是浏览器原来的菜单（刷新、另存为、打印等）。菜单可以用方向键选择，Esc 关闭，点别处或滚动也会关闭；键盘上的菜单键同样能打开。
17. 粘贴保留格式：从 AI 回答、网页、Word/WPS、Excel 复制表格或带格式的文字，粘贴到待办输入框、正文或说明里时，会转成 Markdown 文字保存：表格、代码、粗体、标题、列表和网页链接都保留（指向本地文件等非网页的链接只留文字）。没有格式、只有用 Tab 分隔的多列文字也会转成表格。在 Codex 里用鼠标只选中表格里面的部分复制时，复制出来的内容缺了表格外框，粘贴时会自动补上，照样是表格。Codex 回答里指向本地文件的链接（例如 `DeviceCaroActivity.kt (line 101)`）只显示文件名，鼠标停在上面能看到完整路径，复制时保留原来的 Markdown 链接。表格每列的宽度按这一列最长的一行来分（代码按等宽字体算），类名、文件名这类短内容尽量一行显示完。查看时按格式显示：表格是真正的表格，列宽按内容多少分配；在速记窗口里打开时，窗口按表格需要的宽度和高度从工具栏那边向左、向上放大，整张表一眼看全。屏幕放不下时，窄的地方每一行变成一张卡片，第一列作标题，其余各列写在列名下面。查看页的内容在窗口中间一栏显示，手动放大或最大化窗口时不会铺满两边；标签和时间显示在标题下面一行，底部按钮宽度适中。行内代码有灰底，代码块按语言着色，# 开头的行是标题。以前直接粘贴、保存成 Tab 分隔的表格，打开时也会按表格显示。复制按钮复制的是原来的 Markdown 文字。粘贴到配置的代码里时保持原样，不做转换。粘贴的第一行是粗体或标题时作待办标题（去掉 ** 和 # 符号）；以表格开头时整张表都放进备注，标题用各列的列名。

## 数据与安全

- 本机：`%LOCALAPPDATA%\TNotes\encrypted-cache.json`，上一版为 `.bak`。
- 服务端：`/var/lib/tnotes/vault.sqlite3`，仅 `tnotes` 服务账号能读写。
- SQLite 只保存记录密文、随机 ID 和版本信息；标题、账户、密码、标签、正文均加密。资料库名称、KDF 盐及同步时间属于公开元数据。
- PBKDF2-SHA256（600,000 次）+ HKDF 分离认证密钥和 AES-256-GCM 加密密钥。随机 IV；附加认证数据绑定资料库及记录 ID。主密码不落盘。
- 记住登录时，将派生出的加密与认证密钥用 Windows DPAPI `CurrentUser` 加密后保存为 `%LOCALAPPDATA%\TNotes\remembered-session.dpapi`；不会保存明文主密码或明文密钥。仅同一台电脑的同一 Windows 用户可解密，不能将此文件复制到其他电脑使用；不要放入便携包或服务器备份。
- 笔记窗口使用专用的浏览器配置。每次启动前会关闭这个配置的“保存密码”、自动填充和账户同步，主密码和记录里的账号密码不会进入浏览器的密码库。
- HTTPS 使用随客户端分发的专用证书校验和 IP 主机名校验，不跳过证书验证。证书到期或更换时需要更新客户端证书文件。
- 每天 03:30（服务器时区）对 SQLite 做一致性备份，保留最近七份。仍应另做异地加密备份。
- 已按快速查看需求取消闲置自动锁定。记住登录后，任何能使用当前 Windows 用户的人都可打开资料库，离开电脑应锁定 Windows 或退出本程序登录。复制密码后尝试在三十秒清除剪贴板；浏览器拒绝剪贴板读取权限时会提示手动覆盖。
- 初始安装没有经过独立安全审计。主密码丢失无法恢复；恶意软件、屏幕录制、已解锁电脑以及剪贴板历史不在本软件能防护的范围内。
- 不将本机数据目录、浏览器配置、初始化令牌或 DPAPI 登录记忆复制给其他人。退出登录只清除本机登录记忆，不删除已加密的本机缓存或服务器记录。
- AI 对话记录（开发工具里的小工具，存在 `E:\AIRecords`）也由本机后台（`client/ai-sync.cjs`）同步到这台服务器：每个会话的 gzip 文件按约 148 KB 切块，用记住登录里的资料库密钥加密（AES-256-GCM，附加认证数据 `tnotes-ai-v1:资料库:ID`，和笔记记录互不通用），块 ID 由密钥算出，服务器看不出是哪个会话。它们存在服务器的 `blobs` 表，和笔记的 `records` 表分开、单独限额（32 MiB、4,000 块）：笔记每 30 秒的同步不会下载它们；AI 同步先只拿 ID、版本和大小，只下载变了的块。没有记住登录、服务器未升级或连不上时，记录照样保存在本机，状态写在 `E:\AIRecords\sync-status.json`。

## 运维

服务名称：`tnotes.service`。备份计时器：`tnotes-backup.timer`。

服务器仅开放 HTTPS API 18443/TCP；数据库不开放网络端口。若外网无法连接，检查腾讯云安全组是否放行该 TCP 端口，不要关闭防火墙。

停用服务：`systemctl disable --now tnotes.service tnotes-backup.timer`。此命令不会删除数据。

升级服务器（例如 2026 年 11 月加入 AI 记录的 `blobs` 接口）：在这台电脑上运行

```powershell
powershell -ExecutionPolicy Bypass -File t-notes\server\Update-Server.ps1 -User root
```

脚本用 SSH 把新的 `server.py` 和测试传到服务器的 `/tmp`，先在服务器上跑 `test_store.py`，通过后才备份旧文件（`/opt/tnotes/server.py.bak-时间`）、替换并重启 `tnotes.service`；测试不通过时正在运行的服务不受影响。服务器地址默认取 `%LOCALAPPDATA%\TNotes\server.json`，也可以用 `-Server` 指定。数据库只会多一张空表，旧数据不动；要回退时把备份文件复制回 `server.py` 再重启即可。

## 限制

当前每台电脑使用一个资料库。T 按钮和 `Start-TNotes.cmd` 一次只保留一个窗口：窗口已打开时再次点击只会唤起它（最小化时还原），窗口启动过程中的重复点击会被忽略。若手动在浏览器里另开本机页面，仍会检测本机缓存版本冲突，请保留未保存内容并锁定后重新登录。单个资料库最多 2,000 条记录和约 16 MiB 密文。回收站为软删除。备份文件为密文，导入和恢复都需要主密码。备份恢复到一台新电脑后，如果同步服务器上已有更新的版本，较旧的备份内容会以“冲突副本”保留，不会覆盖服务器上的记录。
