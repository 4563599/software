# T Notes

Windows 轻巧速记小窗 + 三栏资料库。点击窗口右上角的布局按钮切换。

## 使用

1. 解压便携包后运行 `Start-TNotes.cmd`。需要 Edge / Chrome；便携包附带 Node.js 运行时，源码版需要 Node.js 22 以上。
2. 仅首次部署的电脑可以创建资料库。设置一个至少 12 字符的主密码，不能找回。登录时默认勾选“记住这台电脑”；只在自己信任的 Windows 用户下使用。
3. 其他电脑运行相同便携包，首次输入相同资料库名称和主密码登录。不要再次创建资料库。每台电脑分别记住登录，登录密钥不随安装包分发。
4. 打开默认进入快速复制列表，搜索框直接获得焦点。备忘录和提示词可一键复制正文；账号记录分别提供“复制账号”和“复制密码”。支持分类筛选，置顶记录排在前面。点击标题查看详情，点击铅笔进入编辑；小窗保存后返回列表。点击保存立即加密落盘；联网时自动同步，每 30 秒检查一次。冲突记录另存副本，不覆盖任一方。
5. 离线使用需要先在该电脑完成至少一次登录和同步。主密码不会写入服务器配置或客户端安装包。不启用记住登录时，重开窗口需要主密码。
6. 记住登录后，重开窗口、重启程序或重启电脑均无需重复输入主密码；不再闲置自动锁定。右上角“退出登录”会清除当前电脑的登录记忆，并让本程序的其他未编辑窗口一起退出；有未保存修改的窗口会保留内容并提醒先保存后退出。下次打开必须重新输入主密码。
7. 本地服务重启后，新版页面会自动恢复页面校验再重试一次，不要求重置主密码。从旧版升级时，仍打开的旧窗口需刷新一次；出现 `Invalid local request` 不代表主密码错误。
8. 分类与新建类型联动：备忘录对应备忘录，AI 提示词对应提示词，保险箱对应账号密码。新建草稿切换分类会保留输入内容；修改类型下拉框也会选中对应分类。查看其他分类不会自动修改已有记录的类型。
9. 本机安装了独立的 `TNotesLocalBackend` 后台任务，由每分钟守护检查本地健康状态。后台恢复不会刷新窗口或清空未保存内容；点击 T 也会先检查后台，再唤起窗口。便携版可使用 `Launch.ps1 -BackendOnly` 只启动后台。
10. 快捷键：Ctrl+N 新建，Ctrl+S 保存，Ctrl+F 搜索，Esc 取消编辑、返回列表或清空搜索。搜索范围是标题、正文、账户、标签和网站，不包含密码。带 `{{变量}}` 的提示词在列表里点一下会先让你填变量，再复制填好的结果。回收站里的记录，右上角按钮是“恢复”。
11. 每日自动备份：后台每天把加密后的资料库保存为 `文档\TNotes-Backups\tnotes-backup-日期.json`，当天有改动会更新当天的文件，保留最近 30 份。在“同步与备份”里可以改备份文件夹（建议放到另一块硬盘）或立即备份一次。备份文件全部是密文。
12. 导入与恢复：登录后在“同步与备份”里“导入加密备份”，不会覆盖现有记录——本机没有的记录直接恢复，内容不同的另存为“备份副本”，同一个文件重复导入不会重复添加。电脑上还没有资料库时，登录页有“从加密备份恢复”，选择备份文件并输入它的主密码即可；主密码校验通过之前不会写入任何数据。
13. 云端短暂断连会进行最多三次安全重试；记录写入重用同一份密文，避免重复录入。证书校验失败不会跳过校验或反复重试。网络错误日志只记录错误码与次数，不记录账户、密码或正文。

## 数据与安全

- 本机：`%LOCALAPPDATA%\TNotes\encrypted-cache.json`，上一版为 `.bak`。
- 服务端：`/var/lib/tnotes/vault.sqlite3`，仅 `tnotes` 服务账号能读写。
- SQLite 只保存记录密文、随机 ID 和版本信息；标题、账户、密码、标签、正文均加密。资料库名称、KDF 盐及同步时间属于公开元数据。
- PBKDF2-SHA256（600,000 次）+ HKDF 分离认证密钥和 AES-256-GCM 加密密钥。随机 IV；附加认证数据绑定资料库及记录 ID。主密码不落盘。
- 记住登录时，将派生出的加密与认证密钥用 Windows DPAPI `CurrentUser` 加密后保存为 `%LOCALAPPDATA%\TNotes\remembered-session.dpapi`；不会保存明文主密码或明文密钥。仅同一台电脑的同一 Windows 用户可解密，不能将此文件复制到其他电脑使用；不要放入便携包或服务器备份。
- 笔记窗口使用专用的浏览器配置。每次启动前会关闭这个配置的“保存密码”、自动填充和账户同步，主密码和记录里的账号密码不会进入浏览器的密码库。
- HTTPS 使用随客户端分发的专用证书校验和 IP 主机名校验，不跳过证书验证。证书到期或更换时需要更新客户端证书文件。
- 每天 03:30（服务器时区）对 SQLite 做一致性备份，保留最近七份。仍应另做异地加密备份。
- 已按快速查看需求取消闲置自动锁定。记住登录后，任何能使用当前 Windows 用户的人都可打开资料库，离开电脑应锁定 Windows 或退出本程序登录。复制密码后尝试在三十秒清除剪贴板；浏览器拒绝剪贴板读取权限时会提示手动覆盖。
- 初始安装没有经过独立安全审计。主密码丢失无法恢复；恶意软件、屏幕录制、已解锁电脑以及剪贴板历史不在本软件能防护的范围内。
- 不将本机数据目录、浏览器配置、初始化令牌或 DPAPI 登录记忆复制给其他人。退出登录只清除本机登录记忆，不删除已加密的本机缓存或服务器记录。

## 运维

服务名称：`tnotes.service`。备份计时器：`tnotes-backup.timer`。

服务器仅开放 HTTPS API 18443/TCP；数据库不开放网络端口。若外网无法连接，检查腾讯云安全组是否放行该 TCP 端口，不要关闭防火墙。

停用服务：`systemctl disable --now tnotes.service tnotes-backup.timer`。此命令不会删除数据。

## 限制

当前每台电脑使用一个资料库。T 按钮和 `Start-TNotes.cmd` 一次只保留一个窗口：窗口已打开时再次点击只会唤起它（最小化时还原），窗口启动过程中的重复点击会被忽略。若手动在浏览器里另开本机页面，仍会检测本机缓存版本冲突，请保留未保存内容并锁定后重新登录。单个资料库最多 2,000 条记录和约 16 MiB 密文。回收站为软删除。备份文件为密文，导入和恢复都需要主密码。备份恢复到一台新电脑后，如果同步服务器上已有更新的版本，较旧的备份内容会以“冲突副本”保留，不会覆盖服务器上的记录。
