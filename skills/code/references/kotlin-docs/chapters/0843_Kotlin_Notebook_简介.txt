Kotlin Notebook 简介
Kotlin Notebook 入门
Kotlin Notebook is an interactive tool that lets you mix code, visuals, and markdown in one document. You can use notebooks to write and execute code in sections known as code cells, see the results instantly, and write down your thoughts. This setup makes it an excellent tool for rapid prototyping, analytics, and data science. Get to know Kotlin Notebook by completing these steps:
