# Kotlin 编码规范

以用户指定的 [Kotlin 编码规范](https://book.kotlincn.net/text/coding-conventions.html) 为规范依据。名称保持为 `kotlin`。

## 规范正文与额外说明

- [编码规范正文](references/coding-conventions.md)：保留网页原有章节名称、层级和顺序，逐项整理规则、适用条件、例外与关键排版示例。不是只覆盖常用规则的摘要，也不声称逐字复制原文。
- [额外执行说明](references/execution-guidance.md)：技能运行策略与用户要求的项目附加规则，包括临时测试清理、资源优先复用、新增字符串按功能排列；不属于网页规范原文。

不要将执行策略或项目个人习惯混入规范正文，也不要把它们称为 Kotlin 官方强制规则。

## 使用流程

1. 阅读额外执行说明，明确当前任务、项目约定与实际运行环境；本次涉及临时测试或资源时，执行其中对应的项目附加规则。
2. 在规范正文中读取相关章节及其例外。全面审查时通读正文；不要只读取本入口文件就宣称已按全部规范检查。
3. 保留原文的规则强度：必须、建议、优先和允许是不同要求，尤其不能把尾部逗号等可选项改成语法限制。
4. 在用户授权范围内应用规范；资源先检索再决定复用或新增；新增字符串放在对应功能已有字符串下面。交付前检查临时测试清理、行为、兼容性与验证结果。
